# Reason: read me

**Status: live on beta.**

**For:** studies, investigations, articles, research papers and theses.

**Map:** horizontal, read from left to right. Each phase drops down into what was done in it.

**Phases, in order:** Introduction → Literature → Methodology → Results and Inference → Conclusion.

## How it works

1. **A point comes in.** It gets a phase (the writer's pick, the AI's, or a guess from its words offline). The first point in a phase is its main point; the rest are work beneath it.
2. **Spine.** Main points are measured against the main points before them; work against its own phase. The limit is tight at the Conclusion.
3. **Unplanned work.** A lot in a strange direction is offered as a side path ("Something outside the plan").
4. **The answer.** The Conclusion is measured against the Introduction's question.
5. **Structure.** Empty phases, findings with no link to a method, and literature with no source raise notes.

`rules.js` holds the maths; the exact formulas are in the private maths doc.
